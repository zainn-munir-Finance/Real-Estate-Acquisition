# Mobile Home Park (MHP) Acquisition Models

This directory contains financial models designed to evaluate mobile home park acquisitions and assess investment returns.

## Key Features
- Acquisition price and investment analysis
- Revenue and operating expense projections
- Net Operating Income (NOI) analysis
- Debt financing and loan amortization
- Cash flow projections
- LP/GP distribution waterfall and investor returns
- Exit valuation and investment return metrics

## Purpose
To evaluate the financial feasibility of mobile home park acquisitions, analyze potential returns, and support investment decision-making.

## Files
Financial models and supporting analysis related to mobile home park acquisitions.
